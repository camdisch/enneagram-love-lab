# Ennea Connect

"Build a multi-page personality quiz web app centered around relationship Enneagram tests (Mom, Dad, Boyfriend, Girlfriend, Best Friend). The app needs an interactive questionnaire that tallies scores into 9 Enneagram archetypes. It must include a beautiful landing page with viral hooks, an animated loading screen, a limited free results page, and a payment gate card (Stripe placeholder) to unlock the full 'Premium Relationship Blueprint' PDF description. Also, add placeholders for Google AdSense banners at the top, bottom, and mid-quiz positions."
